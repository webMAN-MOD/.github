## Quick Start

1. **Check firmware compatibility:** Confirm that the PS3 system uses a supported CFW or HEN configuration. webMAN MOD requires the appropriate Cobra or supported payload environment.
2. **Download the package:** Obtain the latest release from the official repository and select the appropriate edition for the console setup.
3. **Install and configure:** Follow the release instructions to install the plugin. Open webMAN Setup from the XMB to configure scanning, storage, fan behavior, and other available services.

## FAQ

**1. What is webMAN MOD?**

webMAN MOD is a multifunctional homebrew plugin for PlayStation 3. It extends the console with web and FTP services, content management, network loading, system monitoring, and other utilities.

**2. Does webMAN MOD work with PS3HEN?**

Yes. The project documents PS3HEN support for specified firmware configurations. Check the supported firmware list for the exact version and environment.

**3. Does webMAN MOD support network loading?**

Yes. NETISO allows supported content to be browsed and loaded from a network source. The network server and console configuration must meet the project's requirements.

**4. Can webMAN MOD control the PS3 fan?**

Yes. The plugin includes manual and dynamic fan control, as well as in-game temperature monitoring.

**5. Where can I find the latest version?**

Use the official GitHub Releases page. It provides current packages, release notes, and previous versions.
